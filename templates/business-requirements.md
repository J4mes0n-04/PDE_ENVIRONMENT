# Шаблон бизнес-требования для OpenSpec intake

Этот файл предназначен для копирования в:

```text
workspaces/projects/<project-id>/inputs/REQ-<код>-<краткое-название>.md
```

Пример:

```text
workspaces/projects/device-monitoring/inputs/REQ-DM-001-offline-alert.md
```

## Как пользоваться шаблоном

1. Скопируйте файл в каталог `inputs/` нужного проекта.
2. Замените все подсказки в квадратных скобках на факты.
3. Если ответ неизвестен, напишите `Неизвестно` и добавьте вопрос в раздел «Открытые вопросы».
4. Не выдавайте предположение за факт. Используйте явные пометки `Факт`, `Гипотеза`, `Допущение`.
5. Не вставляйте пароли, токены, персональные данные и другие секреты.
6. Ссылки указывайте на стабильные источники: файл в Git, commit SHA, задачу Redmine, утверждённый макет или отчёт.
7. Передавайте документ в OpenSpec intake только после заполнения обязательных разделов.

Обязательные разделы отмечены словом **Обязательно**. Остальные заполняются, если применимы к изменению.
