# Delta for <domain>

## ADDED Requirements

### Requirement: AC-001 Краткое русское название
The system SHALL демонстрировать проверяемое поведение.

#### Scenario: Основной путь
- **GIVEN** исходное состояние
- **WHEN** пользователь выполняет действие
- **THEN** наблюдается результат

### Requirement: NFR-001 Краткое русское название
The system SHALL соблюдать нефункциональное ограничение.

#### Scenario: Проверка ограничения
- **WHEN** выполняется целевой сценарий
- **THEN** ограничение остаётся выполненным
