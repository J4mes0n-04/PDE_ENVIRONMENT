## Пробелы и вопросы работнику

Ниже — из раздела 14 Intent; для черновика change зафиксированы допущения §12 Intent, вопросы остаются в `proposal.md` как non-blocking, кроме ошибки хранилища (нужен текст до приёмки).

- Браузерная матрица (ОС, версии) — **non-blocking**; допущение: последние stable desktop Chrome, Edge, Firefox, Safari.
- Масштаб браузера/OS кроме 100% — **non-blocking**; приёмка на 100% для 1920×1080 и 3840×2160.
- Дополнительные категориальные фильтры — **non-blocking**; MVP: только поиск по имени + сортировка по имени и дате.
- Правила имён (уникальность, допустимые символы) — **blocking для AC-009** до контракта хранилища; гипотеза: непустое имя, ошибка с причиной при нарушении.
- Ошибка/недоступность локального хранилища — **blocking для приёмки**; в change зафиксирован минимальный SHALL (сообщение + повтор), детальный copy — открытый.
- WCAG уровень — **non-blocking**; проверка контраста акцента на `#202226` до утверждения уровня.
- Первые языки локализации — **out of scope** change (только ресурсы строк).
- Утверждение токенов/шрифтов — **non-blocking** для функциональной приёмки; визуальная приёмка после PM/дизайн.
