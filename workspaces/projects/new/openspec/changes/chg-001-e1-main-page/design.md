# Проектное решение

## Подход

`Э-1` — библиотека комплектов, не рабочая область сборки. `Э-2` открывается только после явного выбора строки или после создания черновика с выбранным способом. Мастер не является корневым экраном: после «Мастер» панель мастера открывается **внутри** `Э-2`.

Черновик с временным именем не появляется в перечне как именованная запись, пока инженер не задал имя и не сохранил на `Э-2`.

Выбор «Мастер» / «Вручную» — отдельный шаг после «Создать комплект», визуально отделённый от строк списка. Третьего способа («готовая комната», шаблон) на `Э-1` нет.

## Компоновка `Э-1` (MVP)

- Боковая навигация веб-панели; пункт конфигуратора → `Э-1`.
- Заголовок «Комплекты» без маркетингового слогана.
- Toolbar: поле поиска; primary «Создать комплект» (32 px); управление сортировкой (имя / дата, asc/desc).
- Основная зона: таблица или список строк 24 px; ≥60% ширины под перечень при наличии комплектов.
- Пустое состояние: факт «комплектов нет» + «Создать комплект»; отдельное состояние «ничего не найдено» при активном поиске.
- Действия строки: открыть, переименовать, удалить (удаление — модальное подтверждение).

## Навигация

```text
[Боковое меню] → Конфигуратор → Э-1
Э-1 → (строка) → Э-2 + BLK-1
Э-1 → (создать → мастер | вручную) → Э-2
Э-2 → (библиотека / закрыть) → Э-1
```

## Нефункциональные ограничения

- Canvas `#17181B`, поверхность списка `#202226`; акцент `#4F8FA6` плоский, без градиентов и glass blur.
- Шрифты IBM Plex Sans / IBM Plex Mono — черновые до утверждения дизайна.
- Строки UI — в локализуемых ресурсах; layout допускает более длинный текст, чем RU.
- 1920×1080 и 3840×2160 @ 100%: без наложений, обрезки обязательного контента, горизонтальной прокрутки страницы.
- Viewport 1440 px: ≥8 строк списка без прокрутки всего chrome страницы.
- Сеть: операции `Э-1` не обращаются к облачным каталогам.

## Зависимости и риски

- API локального хранилища (список, переименование, удаление) — проверить в первый день; при отсутствии API — эскалация срока (Intent §13).
- Правила несохранённых изменений при уходе с `Э-2` наследуются из существующего контракта (`CAN-34`); этот change не переопределяет тексты предупреждений.
- Ошибка загрузки списка: inline-сообщение на `Э-1` и действие «Повторить»; облачный fallback запрещён (`OQ-05` — уточнить copy).

## Восстановление

- Сбой создания черновика не оставляет именованную запись в библиотеке.
- Отмена удаления не изменяет хранилище и порядок списка.
