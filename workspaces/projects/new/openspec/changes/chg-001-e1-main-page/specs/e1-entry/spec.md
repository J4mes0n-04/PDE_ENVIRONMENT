# Delta for e1-entry

## ADDED Requirements

### Requirement: AC-001 Точка входа конфигуратора

The system SHALL при открытии раздела конфигуратора комплектов инженером, уже авторизованным в веб-панели контроллера, показывать экран `Э-1` (библиотека комплектов), а не аналитический дашборд, журнал, настройки сети или иной корневой экран.

#### Scenario: Одно действие из навигации

- **GIVEN** инженер авторизован в веб-панели контроллера в закрытом контуре
- **WHEN** инженер выбирает раздел конфигуратора комплектов в боковой навигации (одно действие)
- **THEN** система отображает `Э-1` с перечнем комплектов или пустым состоянием библиотеки
- **AND** система не отображает третий корневой экран сборки
