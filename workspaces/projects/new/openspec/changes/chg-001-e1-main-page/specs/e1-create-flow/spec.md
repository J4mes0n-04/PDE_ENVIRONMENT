# Delta for e1-create-flow

## ADDED Requirements

### Requirement: AC-006 Создание нового комплекта

The system SHALL на `Э-1` предоставлять действие «Создать комплект», визуально отделённое от строк перечня.

При выборе система SHALL:

1. создать черновик с временным именем;
2. предложить выбор способа: **Мастер** или **Вручную**;
3. после выбора открыть `Э-2` с этим черновиком.

Система SHALL NOT сохранять комплект в хранилище как именованную запись, пока инженер не задал имя и не выполнил явное сохранение на `Э-2`.

#### Scenario: Старт через мастер

- **GIVEN** инженер на `Э-1`
- **WHEN** инженер выбирает «Создать комплект», затем «Мастер»
- **THEN** система открывает `Э-2` с черновиком и панелью мастера внутри `Э-2`, не как отдельный корневой экран

#### Scenario: Старт вручную

- **GIVEN** инженер на `Э-1`
- **WHEN** инженер выбирает «Создать комплект», затем «Вручную»
- **THEN** система открывает `Э-2` с пустой редактируемой заготовкой без автоматического запуска мастера

### Requirement: AC-012 Ровно два способа создания

The system SHALL при создании комплекта предлагать ровно два способа: **Мастер** и **Вручную**.

The system SHALL NOT предлагать на `Э-1` третий корневой способ («готовая комната», «готовое устройство», шаблон).

#### Scenario: Выбор способа

- **GIVEN** инженер инициировал «Создать комплект»
- **WHEN** система показывает выбор способа
- **THEN** доступны только «Мастер» и «Вручную»
