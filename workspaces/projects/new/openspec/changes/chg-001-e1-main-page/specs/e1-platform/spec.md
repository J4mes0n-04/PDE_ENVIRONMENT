# Delta for e1-platform

## ADDED Requirements

### Requirement: NFR-006 Масштабирование Full HD и 4K

The system SHALL на разрешениях 1920×1080 и 3840×2160 при масштабе браузера 100% не допускать наложений элементов, обрезки обязательного контента, недоступных действий и горизонтальной прокрутки всей страницы.

#### Scenario: 4K без регрессий

- **GIVEN** монитор 3840×2160, масштаб браузера 100%
- **WHEN** инженер работает с `Э-1` (список, поиск, создание)
- **THEN** все обязательные элементы доступны без горизонтальной прокрутки страницы

### Requirement: NFR-007 Совместимость с настольными браузерами

The system SHALL корректно работать в согласованной матрице современных настольных браузеров.

До утверждения матрицы система SHALL проходить проверку на текущих stable версиях Chrome, Edge, Firefox и Safari (допущение Intent §12).

#### Scenario: Smoke в четырёх браузерах

- **GIVEN** установлены stable Chrome, Edge, Firefox и Safari на настольной ОС
- **WHEN** инженер открывает `Э-1` и выполняет поиск и «Создать комплект»
- **THEN** список, поиск и primary-кнопка работают без блокирующих ошибок UI

### Requirement: NFR-008 Готовность строк к локализации

The system SHALL хранить все пользовательские строки `Э-1` в локализуемых ресурсах.

The system SHALL NOT захардкоживать пользовательский текст в компонентах так, что смена языка потребует переработки layout.

#### Scenario: Расширенная строка

- **GIVEN** локализованная строка длиннее русского эквивалента
- **WHEN** строка отображается в кнопке или заголовке таблицы
- **THEN** текст переносится или расширяет элемент без перекрытия соседних обязательных элементов

### Requirement: NFR-009 Автономность операций

The system SHALL выполнять загрузку списка и основные операции `Э-1` без обязательного доступа к внешней сети.

#### Scenario: Offline smoke

- **GIVEN** внешняя сеть отключена, контроллер доступен локально
- **WHEN** инженер открывает `Э-1` и выполняет поиск по локальным комплектам
- **THEN** операции завершаются без сетевых запросов к внешним хостам

### Requirement: NFR-010 Кириллица и латиница

The system SHALL корректно отображать кириллицу и латиницу в именах комплектов, поле поиска и элементах управления `Э-1`.

#### Scenario: Поиск кириллицы

- **GIVEN** комплект с именем «Переговорная-А»
- **WHEN** инженер ищет «переговор» без учёта регистра
- **THEN** комплект остаётся в отфильтрованном перечне
