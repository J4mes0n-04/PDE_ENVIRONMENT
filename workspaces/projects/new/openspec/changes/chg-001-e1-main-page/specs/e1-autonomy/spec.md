# Delta for e1-autonomy

## ADDED Requirements

### Requirement: AC-011 Локальное хранилище без облака

The system SHALL загружать перечень комплектов и выполнять операции `Э-1` (поиск, сортировка, открытие, создание черновика, переименование, удаление) только через локальное хранилище текущего контроллера.

The system SHALL NOT обращаться к облачному каталогу комплектов или внешним сервисам для этих операций.

#### Scenario: Закрытый контур

- **GIVEN** контроллер работает без доступа к внешней сети
- **WHEN** инженер открывает `Э-1` и выполняет поиск по локальным комплектам
- **THEN** перечень и операции завершаются успешно без сетевых запросов к облаку

#### Scenario: Ошибка хранилища

- **GIVEN** локальное хранилище недоступно или возвращает ошибку при загрузке списка
- **WHEN** инженер открывает `Э-1`
- **THEN** система показывает служебное сообщение об ошибке загрузки
- **AND** система предоставляет действие повторной попытки загрузки
- **AND** система не подставляет облачный fallback
