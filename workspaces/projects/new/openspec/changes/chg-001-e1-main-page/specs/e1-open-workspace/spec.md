# Delta for e1-open-workspace

## ADDED Requirements

### Requirement: AC-005 Открытие комплекта на Э-2

The system SHALL по явному действию инженера на строке комплекта открывать экран `Э-2` с выбранным комплектом и активировать контекст `BLK-1`.

#### Scenario: Продолжение работы

- **GIVEN** комплект «Переговорная-A» сохранён в хранилище
- **WHEN** инженер на `Э-1` выбирает этот комплект для открытия
- **THEN** система переходит на `Э-2` с тем же комплектом
- **AND** имя комплекта отображается в контексте `BLK-1`

### Requirement: AC-008 Возврат в библиотеку

The system SHALL из `Э-2` предоставлять возврат на `Э-1` и до переключения применять существующие правила обработки несохранённых изменений (наследование `CAN-34`; тексты предупреждений этим change не переопределяются).

#### Scenario: Смена комплекта

- **GIVEN** инженер редактирует комплект A на `Э-2` с несохранёнными изменениями
- **WHEN** инженер инициирует возврат на `Э-1` для открытия комплекта B
- **THEN** система применяет правила предупреждения для комплекта A до перехода
- **AND** на `Э-1` снова виден полный перечень доступных комплектов
