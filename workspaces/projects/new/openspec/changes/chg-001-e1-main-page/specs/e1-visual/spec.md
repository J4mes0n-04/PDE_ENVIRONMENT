# Delta for e1-visual

## ADDED Requirements

### Requirement: NFR-001 Тёмная служебная база

The system SHALL render `Э-1` на тёмных нейтральных токенах: canvas `#17181B`, поверхность списка `#202226` (черновые значения до утверждения дизайна).

#### Scenario: Приёмка фона

- **WHEN** проверяется реализация `Э-1`
- **THEN** доминирует тёмная служебная палитра, а не светлый SaaS-фон

### Requirement: NFR-002 Э-1 не KPI-дашборд

The system SHALL NOT использовать на `Э-1` KPI-плитки, графики, аналитические карточки и виджеты «insights».

The system SHALL отводить не менее 60% ширины основной области под список или таблицу комплектов при наличии хотя бы одного комплекта.

#### Scenario: Содержимое экрана

- **WHEN** `Э-1` отображается с комплектами
- **THEN** на экране нет графиков и KPI-виджетов
- **AND** перечень занимает ≥60% ширины основной области

### Requirement: NFR-003 Плотность списка

The system SHALL использовать высоту строки списка 24 px и высоту primary-кнопки «Создать комплект» 32 px.

#### Scenario: Viewport 1440 px

- **GIVEN** ширина viewport 1440 px
- **WHEN** отображаются toolbar и список комплектов
- **THEN** видно не менее восьми строк списка без прокрутки всей страницы (внутренний скролл списка допустим)

### Requirement: NFR-004 Служебное пустое состояние

The system SHALL в пустой библиотеке показывать только фактическое сообщение и доступное действие создания.

The system SHALL NOT использовать слоганы, маскотов и мотивационный текст.

#### Scenario: Пустая библиотека

- **WHEN** в хранилище нет комплектов
- **THEN** виден только факт отсутствия комплектов и действие «Создать комплект»
- **AND** нет маскота или welcome-слогана

### Requirement: NFR-005 Плоский акцент без AI-chrome

The system SHALL использовать плоский акцент (черновой `#4F8FA6`) для primary «Создать комплект» и фокуса поиска.

The system SHALL NOT использовать градиенты, glass blur и декоративные тени строк списка.

#### Scenario: Primary-кнопка и строки списка

- **WHEN** `Э-1` отображается в состоянии покоя
- **THEN** «Создать комплект» использует сплошную заливку акцента без градиента
- **AND** строки списка в покое не имеют декоративной box-shadow
