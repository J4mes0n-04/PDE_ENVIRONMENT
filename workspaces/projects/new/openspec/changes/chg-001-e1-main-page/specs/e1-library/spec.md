# Delta for e1-library

## ADDED Requirements

### Requirement: AC-002 Перечень комплектов

The system SHALL на `Э-1` показывать все комплекты локального хранилища текущего контроллера в виде плотного списка или таблицы.

Для каждой строки система SHALL показывать:

- имя комплекта;
- дату и время последнего сохранения;
- индикатор несохранённых изменений текущей сессии — только если такая сессия существует для данного комплекта.

#### Scenario: Несколько комплектов

- **GIVEN** в хранилище сохранены комплекты «Переговорная-A» и «Переговорная-B»
- **WHEN** инженер открывает `Э-1`
- **THEN** оба комплекта видны с именами и датами последнего сохранения

### Requirement: AC-003 Поиск по имени

The system SHALL предоставлять поле поиска, фильтрующее перечень по подстроке имени без учёта регистра.

#### Scenario: Фильтрация и очистка

- **GIVEN** на `Э-1` отображаются не менее трёх комплектов
- **WHEN** инженер вводит подстроку, совпадающую только с одним именем
- **THEN** перечень показывает только подходящие комплекты
- **AND** очистка поля поиска восстанавливает полный перечень

#### Scenario: Пустой результат поиска

- **GIVEN** активен непустой поиск без совпадений
- **WHEN** система обновляет перечень
- **THEN** отображается состояние «ничего не найдено», отличное от пустого хранилища
- **AND** инженер может очистить запрос и вернуть полный список

### Requirement: AC-004 Сортировка перечня

The system SHALL сортировать перечень по имени комплекта и по дате изменения в прямом и обратном порядке.

#### Scenario: Смена критерия сортировки

- **GIVEN** на `Э-1` отображаются несколько комплектов с разными именами и датами
- **WHEN** инженер выбирает сортировку по имени по возрастанию
- **THEN** порядок строк соответствует алфавиту имён без учёта регистра
- **WHEN** инженер переключает на сортировку по дате изменения по убыванию
- **THEN** первой отображается строка с самой поздней датой сохранения

### Requirement: AC-007 Пустая библиотека

The system SHALL при отсутствии комплектов в хранилище показывать служебное сообщение об отсутствии комплектов и действие «Создать комплект» без отдельного онбординга.

Система SHALL NOT показывать маскотов, слоганы и маркетинговый текст.

#### Scenario: Первый комплект на контроллере

- **GIVEN** хранилище комплектов пусто
- **WHEN** инженер открывает `Э-1`
- **THEN** видно действие «Создать комплект» без дополнительных экранов
