# Предложение: главная страница конфигуратора (`Э-1`)

## Why — зачем

Инженер интегратора после входа в веб-панель контроллера должен за одно действие увидеть библиотеку комплектов, открыть существующий комплект на `Э-2` или создать новый с явным выбором «Мастер» или «Вручную». Без зафиксированного `Э-1` точка входа превращается в маркетинговый или аналитический дашборд и нарушает целевой срок **2026-09-29**.

Источник: `inputs/intent-e1-main-page.md`.

## What — что меняется

1. Маршрут конфигуратора показывает только `Э-1` (`AC-001`).
2. Плотный перечень комплектов локального хранилища с именем, датой сохранения и индикатором несохранённого черновика сессии (`AC-002`).
3. Поиск по подстроке имени без учёта регистра (`AC-003`); сортировка по имени и дате изменения (`AC-004`).
4. Открытие строки → `Э-2` с контекстом `BLK-1` (`AC-005`).
5. «Создать комплект» → черновик → «Мастер» | «Вручную» → `Э-2` (`AC-006`, `AC-012`); именованная запись только после имени и сохранения.
6. Пустая библиотека — служебное сообщение и действие создания (`AC-007`).
7. Возврат `Э-2` → `Э-1` с правилами несохранённых изменений (`AC-008`).
8. Переименование и удаление с подтверждением (`AC-009`, `AC-010`).
9. Все операции `Э-1` без облачного каталога (`AC-011`).
10. Визуал и платформенные NFR (`NFR-001`…`NFR-010`).

## Scope — область действия

### Входит

- Экран `Э-1` как единственная точка входа в конфигуратор комплектов.
- Загрузка комплектов из локального хранилища текущего контроллера.
- Список/таблица, поиск, сортировка, открытие, создание, пустое состояние, переименование, удаление.
- Тёмное служебное оформление, плотность списка, запреты дашборда/KPI/AI-chrome.
- Совместимость с настольными браузерами, viewport до 4K, подготовка строк к локализации.

### Не входит

- Авторизация и навигация до раздела конфигуратора.
- Проектирование `Э-2`, шагов мастера после выбора способа, устройств и сборки.
- Шаблоны «готовая комната», драйверы, клиент помещения, развёртывание.
- Импорт/экспорт на `Э-1`, индикатор «редактируется другим источником», облачный каталог.
- Переключатель языков и переводы (только вынос строк в ресурсы).

## Measurable outcome

К **2026-09-29** инженер за одно действие из боковой навигации видит `Э-1`, выполняет 100% требований Must (FR-1…FR-12 Intent) и проходит обязательные сценарии UC-1…UC-6 без блокирующих дефектов.

## Open questions — открытые вопросы

- `OQ-01`: обязательная браузерная матрица (ОС, версии) — non-blocking; допущение Intent §12.
- `OQ-02`: масштаб браузера/OS кроме 100% — non-blocking.
- `OQ-03`: категориальные фильтры помимо поиска — non-blocking; MVP без отдельной панели фильтров.
- `OQ-04`: правила уникальности и допустимости имён — **blocking для финальной приёмки AC-009**; нужен контракт хранилища.
- `OQ-05`: точный UX при ошибке хранилища (текст, retry) — **blocking для приёмки**; минимум зафиксирован в `AC-011` / design.
- `OQ-06`: уровень WCAG — non-blocking до согласования.
- `OQ-07`: утверждение токенов и шрифтов — non-blocking для функционала.
