Задачи не являются источником истины Pack. После Ready могут войти в `ase-handoff.md`. Реализация из PDE не запускается.

## 1. Точка входа и маршрутизация

- [ ] 1.1 Пункт конфигуратора в боковой навигации открывает только `Э-1` (`AC-001`).
- [ ] 1.2 Запрет корневых переходов в дашборд, журнал или мастер как отдельный экран.

## 2. Библиотека и поиск

- [ ] 2.1 Загрузка списка из локального хранилища (`AC-002`, `AC-011`).
- [ ] 2.2 Колонки: имя, дата/время сохранения, индикатор черновика сессии.
- [ ] 2.3 Поиск по подстроке без учёта регистра; отдельное empty-search состояние (`AC-003`).
- [ ] 2.4 Сортировка по имени и дате, оба направления (`AC-004`).
- [ ] 2.5 Пустое хранилище (`AC-007`).

## 3. Создание и handoff на Э-2

- [ ] 3.1 «Создать комплект» → черновик → «Мастер» | «Вручную» (`AC-006`, `AC-012`).

- [ ] 3.3 Возврат `Э-2` → `Э-1` с правилами несохранённых изменений (`AC-008`).
