# Контекст проекта

AV Control — offline-first система управления AV-оборудованием помещений. Конфигуратор — веб-среда инженера интегратора для сборки **комплекта**: одной серверной части и связанных клиентских интерфейсов.

**North Star** продукта: Time to Working Room — время от установки до рабочей комнаты. Для конфигуратора это значит: инженер получает редактируемую рабочую основу быстрее, чем собирает всё вручную, и не теряет возможность править любой результат.

Этот проект PDE описывает создание конфигуратора как пользовательского инструмента, а не ядро сервера, драйверы или клиент помещения.
