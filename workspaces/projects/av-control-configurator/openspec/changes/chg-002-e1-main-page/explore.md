## Подтверждённые факты

- Change описывает только UI и поведение экрана `Э-1` (библиотека комплектов) после входа инженера в уже введённый контроллер.
- Исполнитель — инженер интегратора с правом доступа к конфигуратору (`CJM-08`, `KIT01-01`).
- Триггер — начать или продолжить подготовку комплекта (`INT-F1`). `T0` замера Time to Working Room — первое открытие конфигуратора на контроллере.
- Предусловие: контроллер уже доступен через веб-панель; `JRN-ACC-01` и `JRN-SET-01` выполнены или не требуются; `JRN-ACC-04` — сквозной вход, не часть конфигуратора.
- Корневые экраны конфигуратора — только `Э-1` и `Э-2` (APP-06). Мастер — панель внутри `Э-2`, не третий корневой экран.
- `Э-1` — единственная точка входа в конфигуратор комплекта (`UI-01`, `CAN-50`, `KIT01-09`).
- На `Э-1` входят: перечень комплектов; поиск по названию; открытие в `Э-2`; создание черновика с выбором «вручную» / «мастер»; пустое служебное состояние; возврат из `Э-2`; визуал по VIS и токенам; команды импорта/экспорта как вызов `C-PRJ-3` без формата пакета.
- MVP-колонки строки: имя; дата и время последнего сохранения; индикатор несохранённых изменений текущей сессии, если сессия есть (`CAN-30`). Индикатор «редактируется другим источником» (`INV-7`) — только отображение, если данные доступны.
- Способов создания ровно два: мастер и вручную (`CAN-08`, `FORB-05`). «Готовая комната» — `C-PRJ-4`. «Готовое устройство» — не корневой способ на `Э-1`.
- Именованная запись в хранилище появляется только после задания имени и сохранения на `Э-2` (`KIT01-10`, `KIT02-28`).
- Список комплектов читается только из хранилища контроллера. Облачный каталог запрещён (`VAL-04`, `FORB-02`).
- Гипотеза токенов MVP, не финал PM: акцент `#4F8FA6`, IBM Plex Sans / IBM Plex Mono, canvas `#17181B`, surface `#202226` (`FORB-04`).
- Pack Ready для UI `Э-1` не объявляется, пока нет прогона кириллицы RU/EN на именах комплектов и контраста акцента на `#202226` (`FORB-03`).
- При конфликте `VAL-01` и `VAL-02` побеждает `VAL-02` (APP-13): на `Э-1` должны быть видны существующие комплекты; одноразовый «быстрый старт» без возврата в библиотеку запрещён.
- Для экрана `Э-1` при конфликте текста побеждает этот change относительно `AC-002` / `NFR-012` из `chg-001`. Противоречия вне `Э-1` не трогать.
