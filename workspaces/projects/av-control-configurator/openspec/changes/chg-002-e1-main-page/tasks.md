## 2. Маршрутизация точки входа

- [ ] 2.1 Пункт конфигуратора комплектов в боковой навигации открывает только `Э-1` (`AC-035`).
- [ ] 2.2 Нет корневого перехода в дашборд, журнал, настройки сети или мастер как отдельный экран.
- [ ] 2.3 Проверить отсутствие доступа к неавторизованным разделам через прямые ссылки.
- [ ] 2.4 Для несуществующих маршрутов отображать страницу-заглушку с сообщением об ошибке.
- [ ] 2.5 Глубокие ссылки на комплект всегда открывают только в пределах `Э-1`.
- [ ] 2.6 Проверить возврат обратно в библиотеку (назад из других разделов не допускается).
- [ ] 2.7 Сбросить состояние фильтра и выбранных элементов при смене маршрута на `Э-1`.
- [ ] 2.8 Открытие новой вкладки навигирует на корневую страницу `Э-1`.
- [ ] 2.9 Не позволять открывать мастер комплектов как отдельную страницу из навигации.
- [ ] 2.10 Проверить передачу состояния активного раздела в URL без лишних сегментов маршрута.
- [ ] 2.11 Поддерживать плавную анимацию переходов между маршрутами внутри `Э-1`.
- [ ] 2.12 После выхода и повторного входа открывается библиотека (`Э-1`), а не мастер или журнал.
- [ ] 2.13 Недоступность перехода на внутренние экраны без авторизации или роли доступа.
- [ ] 2.14 Глубокие переходы с параметрами (например, фильтр, сортировка) парсятся только если запрошен `Э-1`.
- [ ] 2.15 Нельзя вручную ввести маршрут мастера или настроек — происходит перенаправление на `Э-1`.
- [ ] 2.16 Проверить отсутствие внешних ссылок на неразрешённые разделы.
- [ ] 2.17 Поведение при обновлении страницы: сохраняется ли маршрут только в рамках допустимого (`Э-1`).
- [ ] 2.18 Маршруты связанных окон (например, модалок) открываются только из контекста библиотеки.
- [ ] 2.19 Открытый комплект в `Э-2` не навигирует пользователя за пределы разрешённых экранов.
- [ ] 2.20 История переходов не даёт вернуться на запрещённые маршруты через back/forward браузера.
- [ ] 2.21 Если в адресе есть устаревший маршрут, происходит автоматическое перенаправление на `Э-1`.
- [ ] 2.22 Проверить, что при авторизации и разлогине маршрут всегда сбрасывается на `Э-1`.
- [ ] 2.23 Нет возможности открыть мастер комплектов по прямой ссылке (только из библиотеки).
- [ ] 2.24 Когда пользователь вводит адрес вручную с несуществующим параметром — отображается корректное уведомление.
- [ ] 2.25 Интеграция с системной навигацией: нельзя попасть на журнал или настройки внутри конфигуратора комплектов.
