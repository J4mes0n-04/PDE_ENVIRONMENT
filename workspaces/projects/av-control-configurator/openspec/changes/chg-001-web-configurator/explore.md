- Основной пользователь: инженер интегратора. Конечный пользователь помещения вне конфигуратора.
- Ценности `VAL-01`…`VAL-10`; при конфликте первой комнаты и тиража побеждает тираж.
- Обязательные пути: `JRN-KIT-01`, `JRN-KIT-02`, `JRN-COM-01` (MVP = уборка), `JRN-CHG-01`, `JRN-KIT-03`.

- Экраны: `Э-1` библиотека, `Э-2` рабочее пространство; мастер внутри `Э-2`.
- Способов сборки два: мастер и ручной, в любом сочетании.
- 16 обязательств среды из BRD §6.
- Визуал поверхности «К»: запреты `VIS-BAN-01`…`VIS-BAN-18` со статусом блок.

## Гипотезы, принятые в этот change

- Мастер при создании с нуля: один интерфейс, виджеты на первую страницу.
- Блокирующие ошибки мастера включают отсутствие устройств без явного подтверждения «продолжить с пустой основой».
- Уборка MVP: только неиспользуемые связи, устройства, элементы, медиа; выкладку не блокирует.
- Неполное железо: статусы доступно / ожидается / эмуляция; «ожидается» не мусор.
- Конфигуратор не назначает, кому экран доступен.
- Рабочий визуал MVP: акцент `#4F8FA6`, IBM Plex Sans / Mono.
- Замер времени до рабочей комнаты — протокол без облака; старт — первое открытие конфигуратора на уже введённом контроллере объекта.
