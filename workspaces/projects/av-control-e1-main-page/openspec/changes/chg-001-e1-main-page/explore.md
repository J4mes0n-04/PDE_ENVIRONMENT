- Индикатор чужой блокировки в этом Intent **исключён**.
- Переименование и удаление в этом Intent **входят** (отличие от `OUT-CFG-002`, где это был открытый вопрос).
- Допущение браузеров до матрицы: стабильные настольные Chrome, Edge, Firefox, Safari.
- Проверка 4K: 3840×2160 при масштабе браузера 100%, плюс 1920×1080.

## Гипотезы из раздела допущений Intent

- API переименования и удаления существует в локальном хранилище. Если нет — срок или объём пересматривает владелец продукта.
- Правила допустимости имён задаёт контракт хранилища, пока владелец не утвердил иное: пустое имя отклоняется.
- Дополнительные категориальные фильтры не входят в Must этой недели; фильтр по имени — поиск.
- Масштаб браузера кроме 100% не обязателен, пока не согласован.
