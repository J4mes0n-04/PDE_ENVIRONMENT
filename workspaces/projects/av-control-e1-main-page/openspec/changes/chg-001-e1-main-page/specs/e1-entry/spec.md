# Delta for e1-entry

## ADDED Requirements

### Requirement: AC-001 Точка входа конфигуратора

FR-1 · UC-1 · Intent §2, §10

The system SHALL при открытии раздела конфигуратора комплектов авторизованным инженером за одно действие из боковой навигации показывать экран `Э-1`, а не дашборд, журнал, настройки сети, мастер как корень или иной корневой экран.

#### Scenario: Открыть библиотеку комплектов

- **GIVEN** инженер авторизован в веб-панели доступного контроллера; внешняя сеть может отсутствовать
- **WHEN** инженер выбирает раздел конфигуратора комплектов в боковой навигации
- **THEN** система открывает `Э-1`
- **AND** система показывает все локально доступные комплекты либо пустое состояние
- **AND** третьего корневого экрана сборки нет
