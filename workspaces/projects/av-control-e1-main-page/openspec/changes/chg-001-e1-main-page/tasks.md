# Срезы поставки для ASE

Задачи не являются источником истины Pack. Pack после Ready. Срок Intent: 2026-09-29.

## 1. Макет и маршрутизация

- [ ] 1.1 Макет `Э-1`: список, поиск, сортировка, пустые состояния, primary «Создать комплект».
- [ ] 1.2 Пункт конфигуратора открывает только `Э-1` (`AC-001`).

## 2. Список и поиск

- [ ] 2.1 Загрузка из локального хранилища без облака (`AC-002`, `AC-012`).
- [ ] 2.2 Поиск без учёта регистра и сброс запроса (`AC-003`).
- [ ] 2.3 Сортировка по имени и дате в обоих направлениях (`AC-004`).
- [ ] 2.4 Пустое хранилище отдельно от пустого поиска (`AC-008`).

## 3. Создание и открытие

- [ ] 3.1 «Создать комплект»: черновик, два способа, переход в `Э-2` (`AC-006`, `AC-007`).
- [ ] 3.2 Открытие строки в `Э-2` с `BLK-1` (`AC-005`).
- [ ] 3.3 Возврат с правилами несохранённых изменений (`AC-009`).

## 4. Переименование и удаление

- [ ] 4.1 Переименование с отклонением пустого имени (`AC-010`).
- [ ] 4.2 Удаление с подтверждением и отменой (`AC-011`).
- [ ] 4.3 Проверка API хранилища в первый день; эскалация, если API нет.

## 5. Качество

- [ ] 5.1 Токены и запреты визуала (`NFR-001`…`NFR-005`).
- [ ] 5.2 Full HD и 4K при масштабе 100% (`NFR-006`).
- [ ] 5.3 Локальные шрифты, локализуемые строки, кириллица (`NFR-007`…`NFR-010`).
- [ ] 5.4 Прогон без внешней сети.
