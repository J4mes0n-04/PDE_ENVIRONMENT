# Контекст проекта

AV Control — offline-first система управления AV-оборудованием помещений. Этот проект описывает только **главную страницу конфигуратора** (`Э-1`): библиотеку комплектов после входа инженера в уже доступный контроллер.

Соседний проект `av-control-configurator` держит полный конфигуратор (`OUT-CFG-001`) и более узкий черновик `Э-1` (`OUT-CFG-002`). Текущий Intent расширяет `Э-1`: сортировка, переименование, удаление, 4K, готовность к локализации. Контракт `Э-2`, мастер после выбора способа и деплой сюда не входят.

Пользователь экрана — инженер интегратора. Конечный пользователь помещения конфигуратор не использует.
