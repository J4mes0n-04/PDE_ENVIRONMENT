# Изменение определения DC-001

- Идентификатор результата: `OUT-DEMO-001`
- Текущая / предлагаемая версия Pack: `1.0.0 / 1.1.0`
- Статус: `approved`
- Владелец решения: демонстрационный владелец продукта

## Причина

Синтетическое воспроизведение сетевых событий показало, что окно в 60 секунд создаёт 4,8% ложных оповещений в нестабильном сегменте.

## Изменение

`AC-001` изменён с 60 до 90 секунд. Целевое продуктовое значение p95 ≤ 120 секунд не изменилось.

## Влияние и решение

Нужно повторить измерение времени оповещения и проверку доли ложных срабатываний; реализация ещё не выпущена. Риск остаётся R2. Изменение одобрено для снижения шума оповещений без ухудшения целевого порога результата.
