# Передача в ASE по DEMO-001

- Версия контракта: `1.0`
- Pack: `OUT-DEMO-001 / 1.1.0`
- Риск / автономия: `R2 / A2`

ASE реализует оценку контрольных сигналов, жизненный цикл оповещения и запись аудита. Изменение порога в 90 секунд, цели результата, автоматических физических действий или поддерживаемых протоколов требует согласования PDE; первые два изменения оформляются как изменение определения.

Ожидаются доказательства для `AC-001`, `AC-002`, `NFR-001`, `NFR-002` и проверяемый откат.
