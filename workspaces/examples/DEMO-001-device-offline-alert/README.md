# DEMO-001 — оповещение о потере связи с устройством

Демонстрационный результат уровня R2 для программного обеспечения управления умным зданием. Пример показывает Pack, изменение определения, пакет доказательств, план выпуска, передачу PDE→ASE, обратную связь QSRE и проверку результата.

Все данные синтетические. Каталог нельзя копировать в `projects/` без удаления демонстрационных значений и повторной проверки готовности.
