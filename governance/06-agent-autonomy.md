# Уровни автономии A0–A3

Document ID: PDE-GOV-006  
Type: Policy  
Status: Draft  
Version: 0.1.0

## Уровни

- **A0 Observe** — агент анализирует и предлагает, но не изменяет файлы.
- **A1 Draft** — агент создаёт черновики только в разрешённой рабочей области.
- **A2 Implement** — агент изменяет ветку или worktree, запускает проверки и готовит Pull Request.
- **A3 Operate** — агент выполняет заранее одобренные эксплуатационные действия в ограниченном контуре с audit trail.

## Ограничения

- Автономия не даёт права менять продуктовый смысл, риск или governance.
- По умолчанию PDE work выполняется на A1–A2.
- A3 запрещён для release R3, изменения access control, секретов и нормативных документов без отдельного одобрения.
- Любая внешняя запись выполняется только в явно поставленную пользователем систему и область.
- Агент обязан остановиться при конфликте baseline, недостатке authority или невозможности проверить результат.

## Связь с риском

R и A независимы. Высокая автономия не понижает риск, а высокий риск обычно уменьшает допустимую автономию.
