# Реестр требований соответствия

Document ID: PDE-GOV-020  
Type: Register  
Status: Draft  
Version: 0.1.0  
Owner: Security Owner

## Назначение

Реестр резервирует управляемое место для будущих требований по персональным данным, информационной безопасности, аудиту, гражданской инфраструктуре и другим нормативным областям. Пустой реестр не означает, что требований нет; он означает, что они пока не предоставлены и не утверждены.

## Формат записи

- Obligation ID: `OBL-###`
- Source: документ, договор или решение
- Jurisdiction / scope
- Effective date
- Requirement summary
- Affected products/data/processes
- Control owner
- Implemented controls
- Required evidence
- Status: proposed / applicable / implemented / verified / retired
- Review date

## Начальные записи

На момент версии 0.1.0 применимые внешние требования не зарегистрированы. До их появления действует `16-ai-data-security-policy.md` и консервативная классификация риска.
