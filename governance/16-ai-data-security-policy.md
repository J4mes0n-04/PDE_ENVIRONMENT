# Политика AI, данных и безопасности

Document ID: PDE-GOV-016  
Type: Policy  
Status: Draft  
Version: 0.1.0

## Классы данных

- `public` — допускается во внешних системах.
- `internal` — только утверждённые корпоративные системы.
- `confidential` — минимальный доступ, аудит и запрет внешней передачи без решения Security Owner.
- `restricted` — секреты, персональные данные, ключи управления и чувствительные данные инфраструктуры; не передаются агенту без специально утверждённого контура.

## Агенты и MCP

- Подключается только необходимый MCP с известным владельцем.
- Права выдаются по принципу least privilege.
- Секреты передаются через environment/secret store и не записываются в prompts, traces или Git.
- Внешний skill рассматривается как исполняемая инструкция и проходит review.
- Опасные операции требуют подтверждения человека независимо от уровня A.

## OpenSpace

Только локальный режим. `OPENSPACE_CLOUD_MODE=off` и `OPENSPACE_CLOUD_TELEMETRY_MODE=off` обязательны. Upload/download cloud tools не используются. Локальные traces очищаются от restricted data до сохранения.

## Будущее регулирование

Любое новое обязательство сначала регистрируется в `20-compliance-obligations-register.md`, затем связывается с Pack, control, owner и evidence.
