# Definition of Done PDE-среды

Среда готова к первому пилоту, когда новый участник без автора процесса может:

1. понять структуру по README и пройти doctor;
2. найти нормативные документы и их владельцев;
3. создать проект/Outcome только в `workspaces/projects/`;
4. создать согласованные `pack.md` и `pack.json`;
5. связать Redmine с commit SHA Pack;
6. провести Ready Review и ASE handoff;
7. получить понятные результаты четырёх CI workflows;
8. собрать Evidence Bundle и обработать QSRE feedback;
9. подготовить release и rollback;
10. выполнить Outcome Check и записать следующий сигнал.

OpenSpace, Unleash и observability не являются обязательными для первого пилота. Их отсутствие не должно ломать core workflows.
