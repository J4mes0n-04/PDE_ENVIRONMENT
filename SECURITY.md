# Безопасность PDE-среды

## Текущий статус

Формальные требования по информационной безопасности, персональным данным и отраслевому регулированию пока не предоставлены. Это не означает отсутствие риска. До утверждения специальных требований действует принцип минимальных полномочий и запрет на передачу закрытых данных во внешние сервисы без решения владельца.

## Обязательные правила

- Не хранить секреты, токены, пароли и персональные данные в Git.
- Использовать GitHub Secrets или утверждённое корпоративное хранилище.
- Не включать OpenSpace Cloud; локальная конфигурация должна сохранять `OPENSPACE_CLOUD_MODE=off` и `OPENSPACE_CLOUD_TELEMETRY_MODE=off`.
- Проверять происхождение внешних MCP-серверов и skills до подключения.
- Не выдавать агентам права на прямую запись в защищённые ветки.
- Для изменений R2–R3 фиксировать угрозы, rollback и остаточный риск.
- Регистрировать будущие обязательства в `governance/20-compliance-obligations-register.md`.

## Сообщение о проблеме

Не публикуйте чувствительные детали в публичном issue. Передайте сообщение назначенному Security Owner. Пока роль не назначена, получателем является PDE Lead.
