Ты — UI/UX-дизайнер, специализирующийся на промышленных корпоративных веб-инструментах для инженеров (по духу референсы: IBM Carbon, Siemens iX, GitHub Primer — плотные, сдержанные, тёмные интерфейсы для профессионалов, не консьюмерские продукты).

ЗАДАЧА
Собери один статичный HTML/CSS wireframe-экран веб-конфигуратора AV-системы — редактор визуализации панели управления переговорной комнатой. Пользователь — инженер-интегратор, работает в браузере. Это проверка СТРУКТУРЫ и плотности макета, не финального визуального стиля — часть значений цвета ниже помечена как временная заглушка, замени только их отдельно.

КОМПОЗИЦИЯ ЭКРАНА
Один экран целиком, без модальных окон, без вложенных вкладок. Раскладка:

1. Верхняя полоса — переключатель открытых проектов. Горизонтальный ряд вкладок:
   - «Переговорная 401 — Панель» — активна/выбрана, иконка типа «монитор/экран»
   - «Переговорная 401 — Сервер» — неактивна, иконка типа «сервер/стойка» — визуально отличается от панельной вкладки именно иконкой, не цветом
   - компактная кнопка «+» справа от вкладок — открыть новый проект

2. Узкая полоса под вкладками — быстрый доступ к открытым страницам/попапам: 2–3 пункта, например «Главная страница» (открыта, подсвечена), «Настройки звука», один пункт со значком закрепления (pin).

3. Левая колонка, верхняя часть — дерево интерфейса:
   - Папка «Страницы»
     - «Главная страница» (выбрана, синхронизирована с холстом)
       - «Кнопка: Включить дисплей»
       - «Слайдер: Громкость»
       - «Индикатор: Статус ВКС»
     - «Настройки звука»
   - Папка «Всплывающие окна»
     - «Подтверждение выключения»
   Сверху — поле поиска. У каждого элемента — маленький счётчик использования справа (например «2»).

4. Левая колонка, нижняя часть — библиотека графических элементов: поле поиска + сгруппированный каталог «Кнопки», «Индикаторы», «Слайдеры», «Контейнеры», по 2–3 иконки в каждой группе.

5. Центр — холст. Показана «Главная страница» с сеткой (grid) и линейками по краям, на ней размещены элементы, соответствующие дереву: кнопка, слайдер, индикатор статуса. Один элемент (кнопка) — в состоянии выбран, выделение синхронизировано с деревом слева (тот же пункт подсвечен и там, и там).

6. Правая колонка — инспектор свойств выбранного элемента (кнопки): заголовок с типом и именем, сгруппированные свойства под подзаголовками «Общие» (имя, позиция X/Y, размер W×H), «Внешний вид» (текст, иконка), «Связи» (строка «Используется в 2 связях» как интерактивная, со стрелкой).

ДЕМОНСТРАЦИЯ СОСТОЯНИЙ (важно для оценки результата)
- один пункт дерева — в состоянии выбран (см. выше)
- один пункт меню/тулбара — в состоянии наведение курсора (hover)
- один контрол в библиотеке элементов — в состоянии заблокирован (disabled), заметно тусклее остальных

ИКОНКИ — иконка определяет тип поведения, соблюдать строго
- иконка/текст без хвостового значка = кнопка, немедленное действие
- иконка/текст + маленький шеврон вниз (▾) = раскрывающийся список
- иконка/текст + многоточие (⋯) = открывает панель с расширенными настройками
- поле ввода — всегда с постоянной видимой рамкой и более тёмным фоном, не путать визуально с кнопкой
Иконки — простые однострочные (line icons), без внешних иконочных библиотек/CDN, рисовать как инлайн-SVG или символы — всё должно быть в одном файле.

ТИПОГРАФИКА
Гарнитура — технический гротеск с поддержкой кириллицы (IBM Plex Sans; если недоступен в среде генерации — похожий системный аналог, отметь в комментарии к коду, что финальный шрифт IBM Plex Sans). Моноширинный для счётчиков/идентификаторов — IBM Plex Mono или аналог.
Размеры: 11px — микрометки; 12px — лейблы и второстепенный текст; 13px — основной текст (значения, пункты меню, строки дерева); 14px — заголовки блоков.
Вес: 400 — обычный текст; 500 — активные лейблы и заголовки блоков.

ОТСТУПЫ, РАЗМЕРЫ, РАДИУСЫ
Шкала отступов на основе 4px: 4/8/12/16/24/32px — внутри одного блока использовать один шаг, не смешивать.
Высота контролов: 24px — строки дерева/списка и плотные тулбары; 32px — стандартные кнопки, поля ввода, триггеры дропдаунов.
Радиусы: 0 — строки дерева и списка (сливаются в непрерывный список, не «карточки»); 2px — поля ввода и кнопки; 4px — панели и всплывающие меню.
Минимальная кликабельная зона для иконки — 24×24px даже внутри строки высотой 24px; минимум 4px между соседними кликабельными элементами.

ФОРМАТ ВЫВОДА
Один самодостаточный HTML-файл, инлайн CSS в теге <style> в <head>, без внешних подключений и CDN (ни шрифтов, ни иконок, ни фреймворков). Без JavaScript — это статичный снимок интерфейса. Целевая ширина макета — 1600px, высота произвольная под контент. Вёрстка на flexbox/grid.
