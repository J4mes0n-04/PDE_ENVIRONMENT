# AV Control — кликабельный прототип

Самодостаточный HTML-прототип веб-интерфейса контроллера AV Control.

## Как открыть
Откройте `index.html` в браузере — двойным кликом, без сервера и без интернета
(шрифты IBM Plex подгружаются из Google Fonts; без сети подставится системный шрифт).

## Что внутри
Один файл: разметка, стили и логика. Навигация — по якорям (`#/...`),
поэтому любой экран открывается прямой ссылкой.

Начните с пункта **«Карта прототипа»** внизу боковой панели: там перечислены все
экраны с привязкой к шагам CJM и требованиям.

### Пути первого запуска
- `#/start` — экран первого запуска, создание первого администратора (JRN-ACC-01)
- `#/acc02/source` — восстановление из резервной копии (JRN-ACC-02)
- `#/scl01/source` — новый самостоятельный экземпляр из пакета (JRN-SCL-01)

### Подготовка комплекта
- `#/kits` — хранилище комплектов и создание нового
- `#/kitw/devices` — мастер типового комплекта, 5 этапов (JRN-KIT-01)
- `#/cfg` — конфигуратор: единое рабочее пространство (JRN-KIT-02, C-PRJ-1)

## Конфигуратор: чем управлять

Всё в одном рабочем пространстве `#/cfg` — левая панель инструментов, холст,
инспектор справа и нижняя док-панель со списками.

- **Режим** — одна кнопка в верхнем меню циклически переключает правку и просмотр.
- **Курсор** — стрелка выделяет и двигает, рука панорамирует холст; колесо прокручивает,
  Ctrl + колесо меняет масштаб.
- **Рабочая область** — рамка заданного размера (по умолчанию 1280 × 800). В просмотре
  видно только то, что попало в неё; остальное остаётся на холсте и переносится мышью.
- **Перетаскивание** — теги между однотипными устройствами меняют родителя, тег на элемент
  создаёт связь, элемент из библиотеки на холст добавляет его.
- **Виджеты** — готовые наборы элементов с уже готовыми связями; перемещаются целиком,
  кнопка на рамке включает поэлементную правку.
- **Группировка** — рамкой выделите несколько элементов и нажмите «Сгруппировать».
- **Умные направляющие** — при перемещении показывают выравнивание по соседям и расстояния
  до них, элементы прилипают к линиям.
- **Уровень** — клик по полосе ставит ползунок в точку клика, зажатая ЛКМ тянет его за мышью.

каталог графических элементов интерфейса (EL-*).
