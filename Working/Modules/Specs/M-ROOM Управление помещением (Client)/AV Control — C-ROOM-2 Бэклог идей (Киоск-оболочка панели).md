# Спецификация компонента: `C-ROOM-2 · Киоск-оболочка панели` — Бэклог идей

> **Модуль:** `M-ROOM — Управление помещением (Client)` · **Статус:** draft · **Веха:** пост-`В2` (расширение сверх базового поведения)

## Роли и цели

- **Б-US-1:** Как ИТ-администратор заказчика, я хочу видеть служебную панель диагностики киоска (версия клиента, состояние сети, идентификатор загруженного проекта, время последней синхронизации) без выхода из режима киоска, чтобы проверять состояние панели удалённо, не привлекая интегратора для каждой мелкой проверки.
- **Б-US-2:** Как интегратор, я хочу, чтобы блокировка стартового экрана PIN-кодом (PIN — Personal Identification Number, короткий числовой код доступа) была штатной опцией киоск-режима, чтобы не собирать её вручную под конкретный проект.

## Observable Behaviors

#### Б-OB-1
  **Дано:** панель работает в режиме киоска;
  **Когда:** пользователь с правами ИТ открывает служебную панель диагностики предусмотренным способом (не путать со входом в сервисный режим `OB-2` основной спецификации — здесь режим киоска не покидается);
  **Тогда:** отображаются версия клиента, состояние сетевого соединения, идентификатор текущего загруженного проекта и время последней синхронизации с сервером.

#### Б-OB-2
  **Дано:** интегратор настраивает режим киоска для панели;
  **Когда:** интегратор включает опцию блокировки стартового экрана PIN-кодом;
  **Тогда:** перед показом рабочего экрана панель запрашивает PIN; верный код открывает рабочий экран, неверный — не даёт доступа, без необходимости собирать это поведение вручную средствами клиентского проекта.
