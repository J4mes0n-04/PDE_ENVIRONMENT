## Назначение

Программный доступ внешних систем к серверу: чтение состояния и событий, выгрузка в мониторинг/SIEM и ограниченное управление самим контроллером. Принцип слоя B: система управления отдаёт внутреннее наружу (контроллер — источник), в отличие от слоя C (драйверы, где контроллер — мастер по отношению к внешним устройствам/сервисам). Бронирование и ВКС в этот модуль не входят — они драйверы слоя C и живут в M-DRV.
