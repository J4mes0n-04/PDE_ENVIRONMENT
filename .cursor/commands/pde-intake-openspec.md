# OpenSpec intake перед Outcome

Используйте, когда в проект положили бизнес-требования и ещё нет Pack.

1. Прочитайте skill `.agents/skills/pde-intake-openspec/SKILL.md` и `integrations/openspec/README.md`.
2. Работайте только в `workspaces/projects/<project-id>/openspec/`.
3. Сначала вопросы и change, затем Pack. Не пишите код продукта.
