# Архитектура репозитория

## Разделение платформы и работы

Корень репозитория описывает и автоматизирует PDE-среду. Каталог `workspaces/` содержит конкретные проекты и Outcomes. Благодаря этому изменение процесса не смешивается с изменением продукта.

```text
PROD/
|-- governance/       обязательные нормы
|-- architecture/     описание устройства среды
|-- operations/       инструкции эксплуатации
|-- integrations/     отключаемые адаптеры
|-- templates/        заготовки рабочих артефактов
|-- schemas/          машиночитаемые контракты
|-- scripts/          локальные и CI проверки
|-- workspaces/
|   |-- projects/     реальная работа
|   `-- examples/     только демонстрационные данные
|-- .agents/skills/   повторяемые PDE workflows
|-- .cursor/rules/    контекст Cursor
|-- .codex/           конфигурация Codex
`-- .github/          GitHub workflow и шаблоны
```

## Правило зависимостей

Нормы направляют templates, rules, skills и CI. Исполняемые файлы могут ссылаться на governance, но governance не должен зависеть от поведения конкретного инструмента. Это позволяет отключить Cursor, Codex, OpenSpace, Unleash или observability без потери определения процесса.
