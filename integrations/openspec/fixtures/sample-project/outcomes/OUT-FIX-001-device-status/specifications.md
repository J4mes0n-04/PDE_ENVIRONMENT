# Спецификации поведения

Сценарии перенесены из утверждённого OpenSpec change. Для gates источником истины остаётся pack.json.

- Идентификатор change: chg-001-device-status
- Путь change: integrations/openspec/fixtures/sample-project/openspec/changes/chg-001-device-status

## AC-001 Алерт устойчивого офлайна

The system SHALL показать дежурному алерт, если контроллер остаётся офлайн дольше двух минут.

### Сценарий: Устойчивый офлайн

- **GIVEN** контроллер двери ранее был на связи
- **WHEN** контакта нет дольше двух минут
- **THEN** на рабочем месте дежурного появляется алерт с идентификатором устройства и временем последнего контакта

### Сценарий: Краткий обрыв

- **GIVEN** контроллер двери ранее был на связи
- **WHEN** обрыв связи короче двух минут и связь восстанавливается
- **THEN** алерт устойчивого офлайна не создаётся

## AC-002 Состав алерта

The system SHALL включить в алерт идентификатор устройства и время последнего успешного контакта.

### Сценарий: Обязательные поля

- **WHEN** формируется алерт устойчивого офлайна
- **THEN** оператор видит идентификатор устройства и время последнего контакта

## NFR-001 Без дублей алерта

The system SHALL не публиковать повторный алерт для того же устройства, пока устойчивый офлайн не завершился.

### Сценарий: Повторная проверка статуса

- **GIVEN** алерт по устройству уже открыт
- **WHEN** статус офлайн подтверждается повторно
- **THEN** новый дублирующий алерт не создаётся
